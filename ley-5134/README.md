# Ley 5.134: Establece el "Día de la Bandera de Río Negro" el 01 de octubre de cada año, en virtud de conmemorarse la primera vez que se izó el pabellón provincial, en Viedma, a orillas del río Negro en la Plazoleta del Fundador.
