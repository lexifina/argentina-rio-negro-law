# Ley 4.812: Establece la ejecución de un sistema de seguridad jurídica de la vivienda como derecho humano fundamental. Se garantiza el otorgamiento de escrituras traslativas de dominio sobre inmuebles adjudicados por planes para vivienda única y para el grupo familiar.
