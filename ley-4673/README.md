# Ley 4.673: Garantiza que toda mujer a la que se le haya practicado una mastectomía por cáncer en hospital público provincial, podrá acceder a una cirugía reparadora, con o sin prótesis, segun indicación médica, sin costo alguno por parte del paciente.
