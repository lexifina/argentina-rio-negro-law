Artículo 4°.- El uso de armas menos letales estará autorizado en los siguientes casos:
a) Para inmovilizar, detener o evitar la fuga de quien
represente un peligro inmediato para terceros o para sí mismo.
b) Para actuar en defensa propia o de otras personas.
c) Para impedir la comisión de un delito de acción
pública.
d) Para controlar situaciones de violencia o alteración
del orden público cuando otros medios resulten insuficientes.
