# Ley 5.348: Establece el Régimen de Licencia Familiar por nacimiento en las modalidades: prenatal, maternidad y paternidad y lactancia obligatorio, unificado y remunerado, para todos los agentes públicos que se desempeñen en el ámbito del sector público provincial. Se abrogan las leyes L nº 4542 y 50
