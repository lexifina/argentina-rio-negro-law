# Ley 4.459: Incorpora artículo 159 a la ley K nº 2430 -Orgánica del Poder Judicial-, referido a contribución sobre el monto de los juicios contenciosos o voluntarios que se inicien en cada circunscripción judicial, cuyo beneficiario será el Sindicato de Trabajadores Judiciales.
