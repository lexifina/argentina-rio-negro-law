# Ley 4.570: El Estado provincial, las empresas públicas y privadas de servicios públicos y toda otra empresa que emita facturas con una periodicidad mínima mensual, deberán hacerlo en Sistema Braille gratuitamente, a requerimiento del usuario o consumidor no vidente.
