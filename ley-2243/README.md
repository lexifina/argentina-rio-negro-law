# Ley 2.243: Establece que entidades financieras que se establezcan en la Provincia deberan solicitar autorizacion al Poder Ejecutivo. Exeptua de esta norma a las previstas en el art. 67 inc. 5 de la Const. Nac. Banco Hipotecario y Banco Nac. Desarrollo.
