# Ley 4.490: Ley Impositiva del Impuesto sobre los Ingresos Brutos para el ejercicio fiscal 2010, la ley I nº 1301 establecese la tasa general del tres por ciento -3%- para las siguientes actividades de comercialización -mayoristas y minoristas- y de prestaciones de obras y/o servicios. SUPLEMENTO
