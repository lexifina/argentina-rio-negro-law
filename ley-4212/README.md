# Ley 4.212: La Provincia de Río Negro adhiere a la ley nacional nº 26.141, mediante la cual se instituye el régimen para la recuperación, fomento y desarrollo de la actividad caprina. El Ministerio de Producción es el organismo encargado de la aplicación de la ley nacional.
