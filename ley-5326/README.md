# Ley 5.326: Establece que todos los comercios o locales ubicados en la Provincia de Río Negro que provean el servicio de carga o venta de tarjetas SUBE, deben exhibir un cartel, en un lugar visible al público, con la leyenda de prohibición del cobro de adicionales y/o exigir compra para la prestación
