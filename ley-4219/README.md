# Ley 4.219: Se declara a la localidad de Valcheta como Capital Provincial del Safari. El Poder Ejecutivo instruirá a la Agencia Río Negro Deportes y al Ministerio de Turismo para que incluyan en sus programas las medidas necesarias para el desarrollo, fomento y promoción de la actividad.
